楕円について

95%分布楕円
個々のデータが、平均のまわりにどのくらい広く散らばっているかを示します。楕円が大きいほど、個人差や測定値のばらつきが大きいことを表します。

95%信頼楕円
データから求めた平均値について、母集団の本当の平均がどのあたりにあると推定されるかを示します。楕円が小さいほど、平均値の位置をより精確に推定できていることを表します。

両方を表示すると
外側の分布楕円で「個々のデータがどれくらい散らばっているか」、内側の信頼楕円で「そのデータから平均の位置をどれくらい精確に推定できるか」を同時に確認できます。

※ 信頼楕円は「データの95%が入る範囲」ではありません。

計算方法（概要）
95%分布楕円：標本平均と標本共分散行列 S を用い、(x−μ)ᵀS⁻¹(x−μ) = χ²₂(.95) = 5.991 を境界とします。
95%信頼楕円：母平均の95%信頼領域として、Hotelling の T² に基づく係数を用います。いずれも n < 5 では表示しません。

表示中の楕円の式

x = F2 (Hz)、y = F1 (Hz)。現在の表示対象・楕円モードから算出します。楕円式は A x² + B xy + C y² + D x + E y + F = 0 の形で表示します。
