# External libraries

F1–F2 Classroom loads the following browser libraries over HTTPS.

- QRCode.js 1.0.0 — MIT License — QR code generation
- ExcelJS 4.4.0 — MIT License — Excel (.xlsx) export
- Firebase JavaScript SDK 12.17.1 — Apache License 2.0 — Anonymous Authentication / Realtime Database client

The application does not bundle these library files in this release archive; they are loaded from version-pinned public CDNs.
